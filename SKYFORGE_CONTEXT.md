# SkyForge — язык программирования

SkyForge — русскоязычный язык программирования. Синтаксис на русском,
семантика Python. Транспилируется в Python AST и исполняется на скорости CPython
(флаг `--fast`) либо интерпретируется напрямую.

- Установка: `pip install skyforge-lang`
- Документация: https://skyforge-docs.onrender.com/
- Версия: 1.0.8

**Правило для генерации кода:** используй только те конструкции, которые
описаны в этом файле. Не выдумывай ключевые слова и функции. Если чего-то
нет в списке — считай, что этого нет в языке.

Работает:

Переменные, арифметика, сравнения, логика

Условия, все виды циклов

Функции, дефолтные и именованные аргументы

23. Подводные камни
Верхняя граница для i от 0 до N — не включается. Идёт до N-1.

это, а не this. супер, а не super(). наследник, а не extends.

Конструктор называется инициализация, не init.

Тернарник — A если условие иначе B (условие в середине).

Распаковка в цикле — для k, v в dict.элементы(). dict.элементы() возвращает список пар.

ничего = None, истина/ложь = True/False.

Интерполяция — "{выражение}" внутри строки. Не f-string, не .format().

Лямбда — только одно выражение функ(x) { вернуть ... }.

Внутри """...""" нельзя писать вложенные """. Используй обычные "...".

Дефолты в функциях вычисляются при определении, не при вызове.

вычислить("...") — не песочница. Не запускай недоверенный код.

for ... in по словарю итерирует по ключам. Для пар — .элементы().

сортировать() возвращает копию, сортировать_по — тоже. Оригинал не меняется.

объединить(a, b) для списков возвращает новый список, не мутирует.

обновить у словаря мутирует, слить возвращает новый.

соединить работает с обеих сторон: ["a","b"].соединить("-") = "-".соединить(["a","b"]) = "a-b".

первые(n) и последние(n) работают и для строк, и для списков.

Async ускоряет только I/O — сеть, диск. CPU-задачи не параллелятся (GIL).

Веб-сервер — HTTP. Для HTTPS — reverse proxy (nginx, Cloudflare).

лог — это не функция, а встроенный принт. Можно лог(), лог(1, 2, 3).

Нет def/return — есть функция/вернуть

Нет class/extends — есть класс/наследник

Нет self — есть это

Нет yield — есть выдать

Нет import — есть подключить_питон("...") для Python и подключить "модуль.skf" для .skf

Нет lambda — есть функ(x) { вернуть ... }

Нет f-строк — есть интерполяция "{выражение}"

Нет f"...", r"...", b"..." префиксов

Если не знаешь функции — не изобретай. Используй только те, что в разделе 8.
