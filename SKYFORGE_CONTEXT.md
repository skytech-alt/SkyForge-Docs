# SkyForge — контекст для AI-ассистента

SkyForge — русскоязычный язык программирования, написанный на Python.
Опубликован: `pip install skyforge-lang` (PyPI)
Документация: https://skyforge-docs.onrender.com/
Исходники: github.com/skytech-alt/SkyForge-Docs

## Что уже есть

- **Ядро**: лексер, парсер, интерпретатор на Python (~3000 строк, `skyforge/core.py`)
- **ООП с наследованием** (`класс X наследник Y`, `это`, `супер`)
- **Декораторы** (`@кешировать`, `@повторить(n)`, `@таймер_декоратор`, `@логировать`)
- **Генераторы** (`выдать x`)
- **Async/await** (`асинхронно функция`, `ждать`, `ждать_все`, `ждать_первую`)
- **Опциональные типы** (`функция f(a: число) -> строка`)
- **Pattern matching** (`совпадает x { случай 1 {...} иначе {...} }`)
- **Лямбды** (`функ(x) {...}` или `функция(x) {...}`)
- **Списковые/словарные включения** (`[x*x для x в lst если x > 0]`)
- **Исключения** (`попробовать/поймать/наконец/бросить`)
- **Python-мост** (`подключить_питон("numpy")` — весь PyPI)
- **Веб-фреймворк** (`приложение()`, маршруты, шаблоны, middleware, сессии, `/docs`)
- **ORM** (`создать_модель(...)`, CRUD, запросы, агрегация — поверх SQLite)
- **Тесты** (`@тест("имя")`, `запустить_тесты()`, `SkyForge test`)
- **Стандартная библиотека** (транслит, склонения, русские даты, PBKDF2, JWT, regex, хэши, base64)
- **REPL** (`SkyForge repl`)
- **GUI-лаунчер** (`SkyForge gui`)
- **CLI**: `run`, `check`, `GAZUY`, `repl`, `web`, `test`, `gui`, `version`

## Ключевые команды

```bash
SkyForge repl                    # интерактивная консоль
SkyForge run app.skf             # запустить
SkyForge GAZUY app.skf           # с баннером
SkyForge test tests.skf          # прогнать тесты
SkyForge web app.skf --port 8000 # веб-приложение
SkyForge check app.skf           # проверить синтаксис
```

## Синтаксис — примеры

```skf
// переменные
пусть имя = "Мир"
имя += "!"

// вывод с интерполяцией
лог("Привет, {имя}! 2+2={2+2}")

// функции
функция сумма(a, b) { вернуть a + b }

// дефолты и типы
функция привет(имя: строка, отчество = "") -> строка {
    вернуть "Привет, " + имя
}

// класс с наследованием
класс Животное {
    функция инициализация(имя) { это.имя = имя }
    функция говорить() { вернуть "..." }
}
класс Собака наследник Животное {
    функция говорить() { вернуть "Гав!" }
}

// генератор
функция числа_до(n) {
    для i от 1 до n + 1 { выдать i }
}

// async
асинхронно функция скачать(url) {
    пусть r = ждать http_запрос(url)
    вернуть r
}

// pattern matching
совпадает x {
    случай 0 { лог("ноль") }
    случай [a, b] { лог(a + b) }
    случай {"имя": n} { лог(n) }
    иначе { лог("неизвестно") }
}

// веб
пусть app = приложение()
app.маршрут("/", "GET", функция(з) {
    вернуть "<h1>Привет</h1>"
})
app.запустить(8000)
```

## Как со мной работать

- **Никогда не пиши core.py кусками** — только целиком, иначе IndentationError
- Все патчи — через отдельные скрипты `patch_*.py`, с проверкой якорей
- Файлы всегда в **UTF-8 без BOM**
- Перед пушем — `python -m build`, `twine upload dist\*`
- Render перечитывает `render.yaml`, но иногда нужно вручную обновить Start Command в панели
