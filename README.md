# SkyForge

Русскоязычный язык программирования на Python.

- 📖 Документация: https://skyforge-docs.onrender.com
- 📦 Установка: `pip install skyforge-lang`
- 🧪 69/69 тестов проходят

## Что умеет

ООП, async/await, генераторы, декораторы, pattern matching,
опциональные типы, веб-фреймворк, ORM, тесты, Python-мост.
